## 6. 详细功能规格

### 6.1 Must Have 功能详述

#### F-01 核心 {{appType}} 流程
- **描述：** 用户可完成应用主业务闭环
- **输入：** 用户操作（点击、表单提交）
- **输出：** 界面状态更新 + localStorage 同步
- **异常：** 空输入提示、重复操作防抖

#### F-02 数据持久化
- **存储键：** `app-{{appType}}-state`
- **格式：** JSON
- **迁移：** v1 无版本迁移需求

#### F-03 响应式布局
- **断点：** 640px / 1024px
- **策略：** Mobile-first，flex/grid

### 6.2 界面结构（概要）
| 区域 | 内容 |
|------|------|
| Header | 标题、副标题、主操作 |
| Main | 核心业务区（列表/表单/画布） |
| Footer | 统计/版权（可选） |
