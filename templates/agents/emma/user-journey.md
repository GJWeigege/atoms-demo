## 关键场景详述

### 场景 A：首次构建成功
1. 用户输入「构建 {{appType}} 应用」
2. 选择 {{themeLabel}} 主题，点击构建
3. 23 步流水线逐步完成（约 30–60 秒）
4. 预览 Tab 自动展示可交互应用
5. **成功标准：** 主按钮/表单可点击，数据可保存

### 场景 B：移动端使用
1. 用户用手机打开预览链接
2. 单列布局，触控目标 ≥ 44px
3. 无横向滚动
4. **成功标准：** 核心操作单手可达
